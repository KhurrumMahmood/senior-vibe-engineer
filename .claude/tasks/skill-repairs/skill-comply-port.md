   C8 a green skip; orchestration must surface "skipped" as a distinct state.

   (`self.request.POST.get(...)`) pass undetected; needs a recall fixture
   mechanism plus the same ground-truth oracle.
3. **Ruff-coverable branch unmodeled** — the SKILL.md Phase-1 "Ruff-first"
   guard shape isn't mechanically scoreable by this instrument.
4. **Single-skill generality** — one skill (/prevent-regression), one
   anti-pattern family; rubric portability unproven.
