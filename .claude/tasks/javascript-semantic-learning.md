# JavaScript semantic cohort learning

## Earned contract

The six family-local semantic skills accept `.js`, `.jsx`, `.mjs`, and `.cjs`
only in an explicitly configured checked-JavaScript project. Each resolves the
host's `typescript` package from that host, requires a named `jsconfig.json` or
`tsconfig.json` with `allowJs` and `checkJs`, and never falls back to network,
`npx`, a global compiler, framework inference, or a shared language platform.

- `find-dormant`: TypeChecker reference identity for non-exported top-level
  implementations; CommonJS exports, dynamic registrations, and name strings
  remain conservative uncertainty.
- `find-implicit-state`: promotes only finite JSDoc-backed state authority;
  untyped/open strings remain non-actionable evidence.
- `find-incomplete-sweep`: groups only resolved direct project-function calls
  with explicit object option shapes; methods, dynamic calls, and unknown
  spreads defer.
- `find-semantic-duplication`: confirms only compatible JSDoc or inferred
  return shapes without a compiler-resolved caller/callee relation.
- `map-subsystem`: maps explicit ESM edges and literal `require(...)` edges;
  unresolved edges stay visible.
- `rename-concept`: preserves resolved identifier, alias, shadowing, key, and
  string/comment boundary distinctions while keeping the coupled lexical gate.

## Outcome policy

All six write final artifacts with the selected config, diagnostics,
unresolved modules or identifier resolution, uncovered files, and distinct
checked-JavaScript/JSDoc/compiler-inferred evidence where their artifact model
permits. Missing compiler/config is unsupported; malformed selected JavaScript
is syntax-error; unresolved or config-excluded relevant files are partial,
never clean. Analysis is source read-only and rejects symlinked targets or
outputs at its owned write boundary.

## Verification learning

The focused capability suite creates a host-local offline TypeScript install,
runs its native `npm run typecheck` and `npm test`, then proves final artifacts
across all four JavaScript suffixes. It covers positive and must-not-fire
cases, config/tool absence, malformed source, partial config coverage,
symlinks, copied-skill closure, and source hashing. The sweep fixture proves
the compiler-resolved omission before its deliberately disabled git-trajectory
gate, so the candidate is retained in `gated_out` rather than being claimed as
a forgotten sweep.
