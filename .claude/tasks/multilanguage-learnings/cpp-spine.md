# C++ P7 spine learning packet

The bounded spine uses `/usr/bin/clang++` and `/usr/bin/clangd` from Apple
Clang 21.0.0 plus `/usr/bin/make` GNU Make 3.81. No package was installed and
no network access was used. Those three executables are required. CMake,
compile-database capture tools, clang-tidy, clang-format, IWYU, cppcheck, and
other build/framework adapters are optional and absent.

C++20 is the explicit fixture standard. The preflight proved both C++20 and
C++23 syntax offline, then proposed a C++20/C++23 fixture; C++20 is the
narrower sufficient baseline for the representative class, scoped enum,
overload, namespace, and header-template relationships. The build uses the
Apple toolchain's default libc++ and makes no alternate-library claim.

The transferable mechanism is a strict C++ profile, an exact-case C++ provider,
generic tool/marker doctor, generic source-role inventory, source preservation,
and a Make target that materializes absolute `arguments` entries after the
fixture is copied. A compile database is trustworthy only after structure,
copied-root, language, C++20 mode, completeness, and freshness checks. File
presence and clangd exit zero are insufficient. The fixture is 4,531 bytes;
the exercised runtime closure is 48,011 bytes. Informational local wall times
were 1.68 seconds for clean native build/test, 0.01 for database generation,
0.99 for clangd check, 1.74 for AST JSON, and 0.02 for malformed rejection.

C++ truth remains separate from C. The profile never owns `.c`, `.i`, `.m`,
or `.mm`. Unambiguous C++ declaration/template suffixes are declarations;
`.h` and `.inc` remain ambiguous unless a selected C++ compile command's
dependency closure owns them. Case-sensitive `.C` is handled by the C++
provider because the shared profile registry accepts lowercase suffixes only;
lowercasing it would falsely hand it to C. Modules, macros, overload sets,
templates/instantiations, ADL, virtual dispatch, implicit operations, ODR,
ABI/layout, target/sysroot/defines, and build variants remain semantic limits.

Frozen cohort order is lexical `find-comment-drift`, semantic
`map-subsystem`, then mutation candidate `move-path` only after accepted
lineage. Each still needs its own final artifact, failure lifecycle, copied
closure, and native proof. This spine earns no completed skill support: all 22
rows remain `cpp-pending-implementation`.
