# C17 accepted-evidence structure proposals

## Outcome

`propose-boundary` and `propose-folder-reorganization` now reach independent,
read-only C outcomes without rerunning detection. Both consumers require a
hash-bound human acceptance envelope, a current complete C map, an exact source
and Makefile census, and the relevant already-produced finding:

- `propose-boundary` accepts exactly one explicit-scout
  `confirmed_omnibus` candidate. A ready result accounts for the selected
  function definitions, public declarations, known direct source callers,
  compatibility include, exact `.c`/`.h` creates and edits, Make edits, tests,
  and the regenerated translation-unit census. A reviewed cohesive target
  finishes as `safely_deferred`.
- `propose-folder-reorganization` accepts exactly one three-or-more-member C
  lexical prefix cluster plus the explicit
  `group-three-prefix-translation-units` project convention. A ready result
  accounts for every cluster member, compiler-owned auxiliary headers, include
  edits, Make edits, known first-party callers, tests, and the regenerated
  translation-unit census. Human `keep_flat` and absent-convention decisions
  finish as complete deferrals.

Both write `inspection.json` and `proposal.md` beneath their own report roots.
They never invoke the omnibus, topology, map, Clang AST, or lexical producers.
Malformed, unaccepted, stale-artifact, and stale-source inputs atomically
replace a prior success with a refusal artifact.

## Native and disposable proof

The focused fixture carries one confirmed four-domain omnibus translation unit
and one three-file `billing_*` topology cluster. The unchanged upstream C
producers create the accepted findings and complete compile-database map before
the proposal run. Each proposal then:

1. runs the accepted `make clean compile-db CC=clang`, Make test, and executable
   smoke obligations against the current tree;
2. checks that no audited `.c`, `.i`, `.h`, `.inc`, or Makefile byte changed;
3. applies only the accepted exact plan in a disposable copy;
4. reruns the same native obligations and requires the exact proposed
   translation-unit census; and
5. leaves the host source byte-identical.

The capability test independently applies each emitted plan to a second clean
copy and repeats compile-database regeneration, Make test, and smoke. Copied
single-script consumers also reach their final artifacts from outside the
checkout. No shared C proposal helper was added: with only two consumers, the
validation code remains family-local and self-contained instead of creating a
new copied-closure dependency.

## Honest boundary

The map establishes the selected C17 compile-command snapshot, declarations,
compiler-owned headers, and dependency closure. Human acceptance supplies the
exact seam or move plan and named source-spelling caller impacts. Neither layer
proves function-pointer or callback targets, aliases, runtime reachability,
alternate build variants, external consumers, public/semver compatibility,
ABI, object layout, linkage compatibility, undefined behavior, or conceptual
ownership from filenames. The artifacts propose work for human review; they do
not authorize mutation.
