- Change a lane or gate to `complete` only after its evidence column names a
  committed revision and passing command or artifact.
- Keep failed evidence in the log; add the repair revision rather than erasing
  the failure.
- Parallel lanes may edit only their owned skill directories, cohort test, and
  cohort learning packet. The serial owner alone edits matrices, routers,
  shared harnesses, this tracker, and the expansion plan.
- A review finding becomes gating only when it materially threatens easy
  installation/on-demand execution, honest JavaScript support, a useful final
  outcome, source safety, or likely user experience. Put other worthwhile
  findings in `.claude/tasks/multilanguage-support-backlog.md`.
- Do not add a universal AST, shared executor, transactional installer, or
  cross-skill coordinator to close this phase.
